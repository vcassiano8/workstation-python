# Workstation Python

Ambiente Python científico executado no Ubuntu 24.04 via WSL2.

## Ambiente

- Python
- NumPy
- SciPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter
- Biopython

## Estrutura

- `src/` — código-fonte
- `notebooks/` — notebooks Jupyter
- `data/` — dados
- `tests/` — testes
- `scripts/` — scripts auxiliares
- `docs/` — documentação
